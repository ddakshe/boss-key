**storage** — 켜 둔 사이트 목록과 화면 설정을 그 PC에만 저장합니다.

**storage**
```

```

**sidePanel**
```
확장프로그램의 설정 화면을 브라우저 사이드패널로 띄우기 위해 사용합니다.
```

```
이 확장의 기능 자체가 '사용자가 고른 사이트의 목록을 읽어 표로 다시 그리는 것'입니다. 쇼핑·채용·중고차·주식·게시판 등 어느 사이트에서 켤지는 사용자가 정하므로 대상 사이트를 미리 한정할 수 없습니다. 사이트별 코드가 아니라 화면 구조(반복되는 카드 목록)를 보고 읽는 방식이라 특정 도메인 목록으로 좁힐 수 없습니다. 읽은 내용은 그 탭의 화면을 그리는 데에만 쓰이고, 저장하거나 외부로 전송하지 않습니다. 또한 사용자가 켜지 않은 사이트에서는 화면을 바꾸지 않습니다.
```

**'아니요, 원격 코드를 사용하지 않습니다' 를 고르세요.**
패키지 안의 코드만 실행합니다 — `eval`, `new Function`, 외부 스크립트 로드가 모두 없습니다.
유튜브 영상을 팝업에서 재생할 때 `youtube-nocookie.com` 의 재생기를 **iframe 으로 임베드**하지만,

## 사용자 데이터 — 아무것도 체크하지 않습니다

구글이 말하는 '수집(collect)'은 **데이터를 사용자 기기 밖으로 보내는 것**이에요.
이 확장은 페이지 글자를 읽지만 그 자리에서 화면을 그리는 데만 쓰고, 어디로도
보내지 않아요. 그래서 '웹사이트 콘텐츠'를 포함해 아무것도 해당하지 않아요.

> 보수적으로 가고 싶으면 '웹사이트 콘텐츠'만 체크해도 돼요. 그 경우에도
> 개인정보처리방침이 이미 있으니 추가로 필요한 건 없어요. 다만 항목 세부정보
> 페이지에 '이 확장은 웹사이트 콘텐츠를 수집합니다'로 **공개 표시**돼요.
