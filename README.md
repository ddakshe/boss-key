# 메일함 모드 (가칭, 테스트 버전 0.4)

쇼핑·숙박·공연 사이트의 목록과 상세 화면을 **메일함 / 스프레드시트 / 결재함** 모양으로 바꿔 보여주는 Chrome 확장프로그램이에요.
사이트별 코드 없이, 화면에서 "같은 모양 카드가 반복되는 목록"과 "구매 버튼이 있는 상세 화면"을 스스로 찾아요. 국내·해외 사이트를 최대한 많이 덮는 게 목표예요.

## 설치 / 업데이트

1. `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. 처음: **압축해제된 확장 프로그램을 로드합니다** → `C:\Users\ddaks\ai-works\boss-key\extension`
3. 이미 설치했다면: 카드의 **새로고침(⟳)** 버튼 → 열려 있던 쇼핑몰 탭도 새로고침
4. 확장프로그램 아이콘을 누르면 오른쪽 **사이드패널**이 바로 열려요 (단축키 Alt+Shift+S, 위장 화면의 ⚙ 버튼도 같아요)
   - Chrome은 사용자가 누르는 동작 없이 패널을 자동으로 띄우는 걸 막아요. 한 번 열면 그 창에서는 탭을 옮겨도 계속 열려 있어요.

## 사이드패널

- **이 사이트에서 켜기** 스위치 / 위장 화면 ↔ 원래 화면 버튼
- **이 사이트만 따로 설정**: 켜면 아래 설정이 그 사이트에만 적용
- 템플릿: 메일함 · 스프레드시트 · 결재함
- 숫자·이미지: 숫자 그대로 / 숫자 위장 / 이미지도 숨김
- 이미지 크기 슬라이더: 목록 이미지(14~120px), 마우스 올렸을 때(160~700px). 끄는 동안 바로 바뀌어요
- 보여줄 것: 함께 보면 좋은 상품(보이기·접어두기·숨기기), 광고 상품, 리뷰
- 휠로 바로 전환, 단축키 확인·변경
- 켜 둔 사이트 목록

## 미리보기 · 목록에서 리뷰 보기 (0.4)

- 기본 템플릿은 **스프레드시트**예요.
- 목록에서 줄을 누르면 상품 페이지로 들어가지 않고 **미리보기 팝업**이 떠요. 들어가려면 팝업의 '열기 ↗' 또는 '새 탭'을 눌러요. 패널에서 '바로 들어가기'로 바꿀 수 있어요.
- 리뷰 칸(스프레드시트 '거래수', 메일함 💬, 결재함 '의견')을 누르면 그 줄 아래에 리뷰가 펼쳐져요. 위쪽 바의 '💬 의견 펼치기'는 위쪽 10개를 차례로 불러와요.
- 미리보기와 리뷰는 상품 페이지를 이 탭 뒤에서 몰래 열어 읽어요(누를 때만, 한 번에 하나씩). 그 페이지가 다른 곳으로 이동하거나 새 창을 띄우지 못하게 막아 둬요. 사이트 입장에서는 상품 페이지를 한 번 본 것과 같아요.
- 메뉴·칸 이름에 마우스를 올리면 진짜 이름이 보여요 (예: 거래수 → 리뷰 수, 출고 → 주문·배송 목록). 패널의 '메뉴·칸 이름 → 원래 문구'를 고르면 처음부터 진짜 이름으로 보여요.
- 고친 것: 상세 → 목록으로 돌아오면 원래 화면이 보이던 문제, 검색 결과 카드의 '장바구니' 버튼이나 '즉시 구매' 거르기 메뉴 때문에 목록을 상세 화면으로 잘못 보던 문제.

## 왼쪽 폴더 = 사이트 메뉴

화면의 링크 글자('주문목록', '장바구니', 'Orders', 'Cart' 등)를 찾아 연결해요. 못 찾은 폴더는 흐리게 보여요.

| 메일함 | 결재함 | 스프레드시트 탭 | 사이트 |
|---|---|---|---|
| 받은편지함 | 결재 대기 문서 | 발주내역 | 지금 보는 목록 |
| 별표편지함 | 중요 문서 | — | 내가 별표한 것 (이 PC, 사이트 상관없이) |
| 중요편지함 | 관심 문서 | 관심 | 찜 목록 |
| 보낸편지함 | 기안 문서함 | 출고 | 주문·배송 목록 |
| 임시보관함 | 임시 저장 문서 | 임시 | 장바구니 |
| 휴지통 | 반려 문서함 | 반품 | 취소·반품 |
| 전체보관함 / 편지쓰기 | 전체 문서 | 요약 | 사이트 홈 |

켜기/끄기는 도메인 단위예요. 예: www.coupang.com과 mc.coupang.com(주문목록)이 함께 `coupang.com`으로 켜져요.

## 단축키·마우스

| 동작 | 결과 |
|---|---|
| Alt+Shift+M | 꺼진 사이트면 켜기 / 켜진 사이트면 위장 ↔ 원래 화면 |
| Alt+Shift+S | 설정 패널 열기 |
| 원래 화면에서 그냥 휠 | 바로 위장 화면으로 (휠 전환 켬일 때) |
| 원래 화면에서 Shift+휠 | 진짜 스크롤 |
| 썸네일·📎·첨부에 마우스 | 이미지 크게 + 진짜 값 |
| 줄에 마우스 | 진짜 값 말풍선 |

켜 둔 사이트는 홈·검색·상세 어느 페이지로 가도 위장 화면으로 시작해요. 홈처럼 묶음이 여러 개면 합쳐서 보여줘요.

## 목록 위장표 (메일함)

| 원래 | 메일함 |
|---|---|
| 가격 | 첨부 크기 (1KB = 1,000원 / 외화는 1KB = 1달러·유로·파운드) |
| 할인율 | 제목 앞 말머리 `[30]` |
| 리뷰 수 | 💬 1,234 |
| 판매수 | 👁 1.2만+ |
| 평점 | 받은 시간 (4.8점 → 오후 4:48, 10점 만점은 반으로) |
| 도착일·체크인·공연일 | 받은 날짜 |
| 빠른배송 / 무료배송 / 광고 | 라벨 업무 / 공유 / 참조 |
| 찜 | 별표 (별표편지함에 사이트 상관없이 모임) |

'숫자 그대로' 모드에서는 ★평점, 리뷰, 판매를 그대로 보여줘요. 스프레드시트는 단가·할인·가중치(평점)·거래수(리뷰)·출고수(판매) 칸, 결재함은 금액·의견(리뷰)·조회(판매) 칸이에요.

## 중고차·채용 목록은 칸이 바뀌어요 (스프레드시트)

| 목록 | 칸 (위장 이름 → 진짜) |
|---|---|
| 중고차 | 거래처(제조사) · 품목(차 이름) · 단가 · 기준월(연식) · 누적량(주행거리 km) · 유형(연료 G·D·L·H·E) · 지점(지역) · 방식(변속기 A·M) · 비고(검수·보증·정상) |
| 채용 | 거래처(회사) · 품목(공고) · 지점(지역) · 등급(경력 N·C5·-) · 요건(학력 H·A·B·M·D) · 구분(고용 형태 상시·기간·수습) · 보수(연봉) · 기한(마감) |

목록의 절반 이상이 차(주행거리 + 연식이나 연료)이거나 공고(경력·학력·형태·마감 중 둘)일 때 바뀌어요. 칸 이름에 마우스를 올리면 진짜 이름이 보이고, 패널에서 '원래 문구'를 고르면 칸 이름과 부호가 진짜 말로 나와요.

## 라이트: 못 읽는 사이트는 덮기라도 해요

켜 두지 않은 사이트에서 <kbd>`</kbd> 를 누르면 발주내역 스프레드시트로 덮여요.
그 사이트를 읽지 않고 미리 만들어 둔 화면을 씌우는 거라, **읽을 수 없는
사이트**(로그인 벽, 봇 확인, 사내 시스템)에서도 똑같이 덮여요. 탭 제목도 같이
바뀌고, 한 번 더 누르면 돌아와요.

켜 둔 사이트에서는 같은 <kbd>`</kbd> 가 **진짜 내용을 읽은** 위장 화면을 보여줘요.
키 하나로 둘 다 되는 셈이에요. 설정의 `coverKey` 로 `Space` 로 바꾸거나 끌 수 있어요.

## 영상은 가려만 둬요 (소리는 계속)

유튜브 목록에서 줄을 누르면 **미리보기 팝업 안에서 바로 틀어져요.** 원래 유튜브
화면으로 들어가지 않아요. 기본은 화면이 가려진 채 소리만 나오고, 마우스를 올리면
보여요. '화면 가리기 / 화면 보기' 로 바꿀 수 있어요.


유튜브처럼 영상이 틀어진 페이지에서는 위쪽 바에 `🎞 첨부 미리보기` 가 생겨요.
**마우스를 올린 동안만** 영상 화면을 베껴 보여주고, 떼면 다시 가려져요.
영상을 멈추는 게 아니라 가리기만 하는 거라 **소리는 그대로 나와요.**

## 직접 돌려 보기

확장프로그램을 진짜로 띄워서 사이트마다 위장 화면이 어떻게 나오는지 재는 도구예요.
실제로 쓰는 것과 같은 경로로 돌아가요 (사이트를 미리 켜 두고, 위장 화면의 표를 읽어요).

```bash
node tools/run-ext.mjs                 # 목록에 있는 사이트 전부
node tools/run-ext.mjs 사람인 엔카      # 이름에 걸리는 것만
node tools/run-ext.mjs --url https://... --key example.com
```

`playwright` 가 필요해요 (`npm i -D playwright`, 또는 `PLAYWRIGHT=<경로>`).
칸마다 몇 줄이 채워졌는지와 첫 두 줄을 보여줘요.

```
■ 사람인 검색 — 목록 · 40줄
  칸   No 40/40 · 거래처 40/40 · 품목 40/40 · 지점 40/40 · 등급 40/40 · 요건 40/40 …
  줄   1 | 씨메스로보틱스(주) | Backend (Python) 개 | 서울 강남구 | C3 | B | 상시 |  | 12/01(화)
```

쿠팡·네이버쇼핑처럼 자동화를 막는 사이트는 이 도구로 못 열어요. 그건 직접 봐야 해요.

## 알려진 한계

- 화면에 그려진 것만 읽어요. 늦게 불러오는 이미지·리뷰는 비어 있을 수 있어요
- 화면에 보이는 몇 개만 그리는 목록(NOL 숙소)은 한 번에 몇 줄만 읽혀요
- 정렬 메뉴가 펼치기 전엔 페이지에 없는 사이트(무신사, 29CM, 아고다, 하이마트)는 사이트 정렬 대신 우리 정렬을 써요
- 상품명이 h1이 아닌 사이트는 탭 제목·og:title로 추측해요
- 주소창, 방문 기록, 회사 네트워크 기록은 그대로 남아요
- 테스트 버전은 모든 사이트에 content script가 들어가요 (`tabs` 권한 포함). 스토어 버전은 사이트별로 권한을 받는 방식으로 바꿔야 해요
